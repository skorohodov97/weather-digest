# Weather Digest

Консольная утилита на Node.js, которая получает прогноз погоды из Open-Meteo для одного или нескольких городов. Для каждого города она находит координаты, запрашивает прогноз, выводит таблицу в терминал и сохраняет JSON-отчёт.

## Требования

- Node.js 20 или новее;
- доступ в интернет для первого запроса по городу;
- npm.

## Установка

```bash
git clone <адрес-репозитория>
cd weather-digest
npm install
```

Зависимостей у проекта нет: используется встроенный `fetch` из Node.js. Команда `npm install` нужна для стандартной подготовки npm-проекта.

## Настройка

Скопируйте `.env.example` в `.env` и при необходимости измените значения. Файл `.env` не попадает в Git. Чтобы Node.js прочитал этот файл, запускайте утилиту с параметром `--env-file`:

```bash
node --env-file=.env src/index.js --city "Москва"
```

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `REQUEST_TIMEOUT_MS` | `5000` | Лимит ожидания одного HTTP-запроса в миллисекундах. |
| `GEOCODING_API_URL` | URL Open-Meteo Geocoding | Базовый URL API поиска города. |
| `FORECAST_API_URL` | URL Open-Meteo Forecast | Базовый URL API прогноза. |
| `REPORTS_DIRECTORY` | `reports` | Каталог JSON-отчётов и кэша. |
| `TEMPERATURE_UNIT` | `celsius` | Единицы температуры: `celsius` или `fahrenheit`. |
| `PRECIPITATION_UNIT` | `mm` | Единицы осадков: `mm` или `inch`. |

Переменные также можно передать напрямую из терминала. Пример для PowerShell:

```powershell
$env:REQUEST_TIMEOUT_MS = "3000"
npm start -- --city "Москва"
```

## Запуск

```bash
npm start -- --city "Москва" --days 3
```

Параметры:

- `--city` — обязательное название города. Несколько городов передаются через запятую.
- `--days` — количество дней прогноза от 1 до 7; по умолчанию `3`.
- `--no-cache` — игнорирует отчёт за текущую дату и принудительно запрашивает свежие данные.

Примеры:

```bash
npm start -- --city "Нижний Новгород"
npm start -- --city "Москва,Санкт-Петербург" --days 5
npm start -- --city "Москва" --days 1 --no-cache
```

## Пример вывода

```text
Москва, Россия
Координаты: 55.75204, 37.61781
Часовой пояс: Europe/Moscow
+------------+----------+-----------+------------+
| Дата       | Мин., °C | Макс., °C | Осадки, мм |
+------------+----------+-----------+------------+
| 2026-09-13 | 7.7      | 16.2      | 0          |
+------------+----------+-----------+------------+
```

Отчёт сохраняется в файле вида `reports/Москва-2026-09-13.json`. При повторном запуске в тот же день с тем же количеством дней утилита использует этот файл как кэш.

## Ошибки и коды завершения

Утилита обрабатывает следующие ситуации:

- некорректные аргументы командной строки;
- город не найден;
- сетевой сбой;
- превышение таймаута;
- HTTP-ответы 4xx и 5xx;
- некорректный JSON в ответе API.

Код завершения `0` означает успех. Код `1` выставляется при ошибке аргументов или если не удалось обработать хотя бы один из городов. Ошибка одного города не отменяет обработку остальных.

## Postman

Экспортированные файлы находятся в `docs/postman/`:

- `weather-digest.postman_collection.json` — коллекция с геокодингом и прогнозом;
- `weather-digest.postman_environment.json` — окружение с переменными.

В коллекции сохранены примеры успешного ответа, пустого результата поиска города и ответа `400`.

## Структура проекта

```text

  services/weatherService.js   обработка городов
  storage/reportStorage.js     JSON-отчёты и кэш

  index.js                     запуск приложения
docs/postman/                  экспорт Postman
reports/                       локальный кэш, не добавляется в Git
```
